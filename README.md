# Практические работы по дисциплине «Проектирование информационных систем»

**Вариант 5:** Файлы (название файла, дата создания, размер в байтах).

В репозитории собраны практические работы по курсу ПИС (язык Python).

## Выполненные работы

### Практическая работа 1. Введение в ООП
Реализована базовая программа для создания объекта `FileObject` из текстовой строки. 
* Поддерживается разбор свойств разных типов: строка (в кавычках), дата (`гггг.мм.дд`), целое число (размер в байтах).
* Свойства в строке могут идти в любом порядке и разделяться произвольным количеством пробелов.

### Практическая работа 2. Рефакторинг кода (разбиение на функции) и Git
* Добавлены 2 новых типа объектов на основе базового класса: `AudioFile` (добавлено время длительности `чч:мм`) и `ArchiveFile` (добавлены коэффициент сжатия и алгоритм).
* Добавлено чтение списка объектов из многострочного текста и из текстового файла.
* Код разбит на небольшие функции (до 10 строк каждая) в соответствии с принципом единственной ответственности (SRP) и оформлен по стандарту PEP 8.

### Практическая работа 3. Декомпозиция на классы и обработка ошибок
* Логика разбора строк разделена на отдельные вспомогательные классы (`TokenRecognizer`, `PropertyExtractor`, `ObjectBuilder`, `ObjectParser`) с соблюдением принципов SOLID.
* Добавлена обработка исключений (`ParseError`, `UnknownObjectTypeError`, `InvalidPropertyError`) для отлова некорректных входных данных.
* Написаны модульные тесты (`unittest`) в файле `test_1.py` для проверки всех сценариев работы и ошибок.

### Практическая работа 5. Инструментальные средства анализа кода и тестирование
* Проведен статический анализ кода (`pylint` / `flake8`) и динамический анализ покрытия и памяти (`coverage`, `tracemalloc`).
* Выполнено профилирование производительности (`cProfile`) и оптимизированы узкие места при парсинге данных.
* Добавлены документационные строки (`docstrings`) и сгенерирована автодокументация по коду с помощью `pydoc`.

